# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://cyberhacks.netlify.app/

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the ```Richard developer``` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
